HardSub Reader

Reads hardcoded (burned-in) video subtitles aloud in real time. Works with any video source: streaming sites, media players, video calls, or recorded lectures, in any language the OCR engine supports, including right-to-left scripts such as Arabic.

Requirements and installation

  • Windows 10 or 11. Windows 11 is strongly recommended: it provides the high-accuracy OneOCR engine.
  • Install the add-on from the .nvda-addon file and restart NVDA.
  • On Windows 11, shortly after you install the add-on and restart NVDA, it offers once to set up the high-accuracy OneOCR engine. Answer Yes and approve the administrator prompt; the setup copies the engine files from your own Snipping Tool. You can also start this setup at any time with the "Set up the high-accuracy OneOCR engine now" button in the add-on settings. If the engine is not set up, the add-on uses a lower-accuracy fallback engine automatically.

Usage

  • NVDA+alt+shift+s: toggle subtitle reading. A high beep confirms the OCR engine is ready.
  • Whether a new subtitle interrupts the one being spoken is controlled from the add-on settings; a keystroke for it can be assigned in the NVDA Input Gestures dialog, HardSub Reader category.
  • Subtitle reading locks to the window that was focused when you started it, so you can switch to other windows without the add-on reading their text. To read a different video, stop and start reading again from that window. If the video window is closed, reading turns off and announces it. Note: with some players, subtitles may pause while the video window is completely covered by another window.

The toggle keystroke can be reassigned in the NVDA Input Gestures dialog under the HardSub Reader category.

Settings

NVDA menu, Preferences, Settings, HardSub Reader:

  • Response speed: how quickly new subtitles are noticed. Faster settings use more CPU and battery.
  • Part of the video window to scan: subtitles usually sit at the bottom, so scanning only the bottom third is fastest and most reliable. Choose a larger area if a video shows text higher up.
  • Filtering of OCR misreads: the add-on can double-check each line across scans before speaking it, which prevents garbled text during subtitle fade animations at the cost of a small delay. Normal is recommended.
  • Do not repeat a line seen again within this many seconds: prevents the same subtitle being spoken twice when it flickers or stays on screen.
  • Stop reading the previous subtitle when a new one appears: keeps speech in sync with fast dialogue; turn it off if you prefer every line read to the end.
  • Subtitle language code: used by the fallback engine on systems without OneOCR; the high-accuracy engine detects languages automatically.
  • Read only subtitles in this language: when ticked, lines written in a different alphabet are skipped. Useful for videos that mix languages, so a channel logo or credits in another language are not read out. Type a code such as ar, en or ja in the language box above; capitals and regional forms such as ar-SA also work. If a code is not recognised, every language is read and a message says so. Leave the box unticked to read every language on screen, which is the default.
    Languages written in different alphabets, for example Greek and English, are separated reliably. Languages that share an alphabet, for example Spanish and English, are told apart using common words and letters: a longer line is usually identified correctly, while a short one may still be read even if it is in another language. This is intentional, so that dialogue is never silenced by an uncertain guess.
  • Text to never read aloud: a checklist of common noise (bare timestamps, short ALL-CAPS watermarks, "Skip Ad" prompts, symbol-only misreads) plus a box for your own phrases, one per line. A typed phrase is filtered only when it exactly matches a whole subtitle line, so it will not accidentally remove dialogue that merely contains the same words. Starting a line with regex: uses a regular expression instead of literal text, for advanced patterns.
  • Save a detailed diagnostic log: off by default. When switched on, the add-on records what the recognition engine read, what it decided to speak, and what it skipped, in %TEMP%\hardSubReader_sidecar.log. This includes the text of the subtitles themselves, so leave it off unless you are investigating a problem or preparing a bug report. The file is started again once it grows past a few megabytes.
  • Restore default settings: returns every setting on this page to how it arrived, including clearing your own list of text never to read aloud. You are asked to confirm first, and nothing is saved until you select OK, so Cancel still keeps your previous settings. The high-accuracy engine setup is not affected.

Troubleshooting

  • A low beep means the OCR helper stopped; it restarts automatically. Repeated failures produce a spoken message.
  • The add-on keeps one diagnostic file on your computer: hardSubReader_sidecar.log in your temporary folder. It records only timestamps and technical error details for troubleshooting; it never contains subtitle text, screenshots, or anything about what you watched. It is capped at about one megabyte and can be safely deleted at any time.
  • If you hear a note about the lower-accuracy engine, open the HardSub Reader settings and use the "Set up the high-accuracy OneOCR engine now" button.
